# Ride Booking History System (Linked List - Java)

## 📌 Description
This project simulates a ride booking history system like Uber/Ola backend logs using a Linked List.

## 🚀 Features
- Add new ride
- Delete last ride
- View all rides
- Search ride by location
- Reverse ride history

## 🧠 Data Structure Used
- Singly Linked List

## 🛠️ How to Run
1. Compile:
   javac *.java

2. Run:
   java Main

## 📷 Example
Add rides, search by location, and reverse history dynamically.
